Las cinco familias de códigos de estado

Esta sección presenta una visión general de las categorías de códigos HTTP. Cada familia se identifica por su primer dígito y agrupa respuestas con un propósito común: informar, confirmar un éxito, redirigir, señalar un error del cliente o reportar una falla del servidor. La tabla siguiente sirve como referencia rápida y, debajo, cada categoría se detalla con sus estados individuales más comunes.

Referencia rápida

Tabla de categorías

Rango de códigos y descripción general de cada familia.

Categoría Rango de Códigos Descripción
1xx 100 – 199 Respuestas informativas: indican que la solicitud fue recibida y el proceso continúa.
2xx 200 – 299 Respuestas de éxito: la solicitud se recibió, entendió y procesó correctamente.
3xx 300 – 399 Redirecciones: se necesita una acción adicional, normalmente ir a otra URL, para completar la solicitud.
4xx 400 – 499 Errores del cliente: la solicitud tiene un problema atribuible a quien la envió (datos inválidos, sin permisos, recurso inexistente).
5xx 500 – 599 Errores del servidor: el servidor falló al intentar cumplir una solicitud aparentemente válida.
Detalle

Cada categoría, código por código

Los estados individuales más frecuentes dentro de cada familia, con un ejemplo de su uso en una API como la de EncomiExpress.

1xx

Informativos

en tránsito

El servidor confirma que recibió la solicitud y sigue procesándola. Son respuestas provisionales, poco frecuentes en APIs REST tradicionales, y no requieren que el cliente haga nada más que esperar.

100Continue — el servidor recibió los encabezados y el cliente puede continuar enviando el cuerpo de la solicitud.
101Switching Protocols — el servidor acepta cambiar de protocolo, por ejemplo al abrir un WebSocket.
102Processing — la solicitud fue recibida pero aún no hay una respuesta disponible.
103Early Hints — adelanta encabezados de la respuesta final mientras el servidor sigue procesando.
2xx

Éxito

entregado

La solicitud se recibió, entendió y procesó correctamente. Es la respuesta esperada en el flujo normal de la API: la entrega sin novedad.

200OK — la solicitud se procesó con éxito, por ejemplo al consultar el listado de envíos.
201Created — se creó un nuevo recurso, como al registrar una nueva encomienda.
202Accepted — la solicitud fue aceptada para procesarse, pero aún no ha finalizado.
204No Content — la operación fue exitosa pero no hay contenido que devolver, como al eliminar un registro.
3xx

Redirección

ruta desviada

Se necesita una acción adicional, normalmente seguir otra URL, para completar la solicitud original.

301Moved Permanently — el recurso se movió de forma definitiva a otra URL.
302Found — redirección temporal a otra ubicación.
304Not Modified — el recurso no cambió desde la última consulta; el cliente puede usar su copia en caché.
307Temporary Redirect — redirección temporal que conserva el método HTTP original.
4xx

Error del cliente

remitente

La solicitud tiene un problema atribuible a quien la envió: datos mal formados, autenticación faltante, permisos insuficientes o un recurso inexistente.

400Bad Request — la solicitud tiene una sintaxis o datos inválidos.
401Unauthorized — falta autenticación válida para acceder al recurso.
403Forbidden — el cliente está identificado pero no tiene permiso para esa acción.
404Not Found — el recurso solicitado no existe, como una encomienda con un ID inválido.
409Conflict — la solicitud entra en conflicto con el estado actual del recurso.
422Unprocessable Entity — la sintaxis es correcta pero los datos no cumplen las reglas de negocio.
5xx

Error del servidor

transportista

El servidor falló al intentar cumplir una solicitud aparentemente válida. La falla no es del cliente, sino de la infraestructura o la lógica del backend.

500Internal Server Error — ocurrió un error inesperado en el servidor.
502Bad Gateway — un servidor intermedio recibió una respuesta inválida de otro servidor.
503Service Unavailable — el servidor no está listo para atender la solicitud, por ejemplo en mantenimiento.
504Gateway Timeout — un servidor intermedio no recibió respuesta a tiempo de otro servidor.
